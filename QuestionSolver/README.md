# 智能题目解答助手（QuestionSolver）

一款**单文件、免安装**的 Windows 桌面软件：截图 → 自动识别题目 → 调用豆包（火山方舟）视觉大模型 → 返回答案、解题思路与详细步骤，并支持一键复制。

---

## 一、支持的操作系统环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | **Windows 10 / 11（64 位）**。EXE 在 Windows 上打包，原生运行于 Windows。 |
| 运行依赖 | **无任何外部依赖**。所有 Python 运行环境、界面库、网络库均已内嵌进单个 EXE。 |
| 其他要求 | ① 可联网（需访问火山方舟 API）；② 一个**火山方舟 API Key**（在软件内填写一次即可，无需安装任何客户端）。 |
| 权限 | 普通用户权限即可，无需管理员安装；可直接放在 U 盘/任意文件夹双击运行。 |

> 若需在 macOS / Linux 上使用：本仓库提供的 `solver.py` 源码本身跨平台，用 `pyinstaller --onefile solver.py` 在对应系统重新打包即可得到该平台的免安装可执行文件。Windows EXE 不可直接在 macOS/Linux 运行。

---

## 二、运行方式

1. 将 `QuestionSolver.exe` 复制到你喜欢的任意位置（桌面、U 盘、某文件夹均可）。
2. **双击 `QuestionSolver.exe`** 即可启动，无需安装、无需解压、无需配置环境变量。
3. 首次启动会弹出主界面；请先点「⚙ 设置」填入 API Key（见下方第四节），之后即可正常使用。

> 配置文件 `config.json` 会自动生成在 `QuestionSolver.exe` 同目录下，用于保存你的 API Key / 模型等设置，请勿误删（删除后需重新填写设置）。

## 三、具体使用步骤

### 第 1 步：准备 API Key（仅需一次）
1. 打开浏览器访问火山方舟控制台：<https://console.volcengine.com/ark>
2. 注册/登录后，在「API Key 管理」中**创建 API Key** 并复制。
3. 在软件内点击「⚙ 设置」，把 Key 粘贴到「火山方舟 API Key」一栏；可点击「显示密钥」核对。
4. 点击「保存」。设置即生效，后续启动会自动读取。

> 默认模型为 `doubao-seed-2-0-lite-260215`（支持图片输入的视觉模型）。如需更强模型（如 `doubao-seed-2-0-pro-260215`），可在设置中修改「模型 ID」。

### 第 2 步：截图解题
1. 把屏幕上想要解答的题目（网页、PDF、图片、试卷照片等）调整到可见位置。
2. 回到软件，点击「📷 截图解题」。
3. 屏幕会蒙上一层半透明遮罩，**按住鼠标左键拖拽框选题目区域**，松开即完成截取。
   - 按 `Esc` 或**鼠标右键**可取消截图。
4. 软件自动把截图发送给豆包视觉模型进行识别与解答（通常几秒到十几秒）。

### 第 3 步：查看与复制结果
- 解答会出现在主界面文本区，结构为：`【最终答案】/【解题思路】/【详细步骤】`。
- 支持**中文、英文、数学公式（$...$ LaTeX 行内公式）、流程图与图表**类题目的识别与解答。
- 点击「📋 复制答案」即可把全部内容复制到剪贴板，粘贴到微信 / Word / 笔记中。
- 「🔁 重新求解上一张」可对新换的提示词重算同一张截图；「💾 保存」可导出为 txt；「🗑 清空」清空界面。

## 四、获取火山方舟 API Key（图示步骤）

1. 访问 <https://console.volcengine.com/ark/region:ark+cn-beijing/apikey> 进入「API Key 管理」。
2. 点击「创建 API Key」，命名后生成一串以 `ak-` 开头的密钥，复制保存。
3. 在软件「设置」中粘贴保存即可。（API 调用按火山方舟计费，新用户通常有免费额度。）

## 五、常见问题

- **提示「缺少 API Key」**：点「设置」填写并保存 Key。
- **API 返回 401/403**：Key 无效或无权限，请检查 Key 是否正确、是否在该区域开通对应模型。
- **点击「截图解题」没反应 / 无法截图**：新版已对该环节做兜底——若仍失败，会弹出具体错误窗口，请截图该弹窗内容发我定位。常见原因：① 用的是旧版 EXE（请重新下载本文档同目录最新的 `QuestionSolver.exe`）；② 系统缩放导致 picker 异常，可尝试把 Windows「设置→显示→缩放」临时调到 100% 后重试；③ 多显示器环境下主屏坐标异常，建议先在主显示器上框选。
- **截图区域偏位**：本软件已做高 DPI（缩放）适配；若仍异常，请确认 Windows 显示缩放为整数倍（如 100%/150%），或重启软件重试。
- **识别效果不理想**：框选时尽量只保留题目本身、排除无关界面；对模糊照片可先放大再截取。
- **网络超时**：求解依赖联网，请确认网络可访问 `ark.cn-beijing.volces.com`。

## 六、源码与二次打包（开发者）

- 源码：`solver.py`（Python 3.10+）。
- 依赖：`requests`、`pillow`、`pyinstaller`（仅打包时需要）。
- 重新打包为免安装 EXE：
  ```bash
  pip install requests pillow pyinstaller
  pyinstaller --onefile --windowed --hidden-import PIL.ImageTk --hidden-import PIL.ImageGrab --name QuestionSolver solver.py
  # 产物：dist/QuestionSolver.exe
  ```
